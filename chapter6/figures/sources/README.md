### Chapter 6: other figure sources

QGIS projects, SQL scripts and images of maps of the chapter that the book does not include. The
producers of the figures of the book are in the parent folder.

The QGIS projects read PostgreSQL databases on `localhost` (`Delhi`, `DelhiTZ`, `London`,
`SemanticTraj`), which the scripts of this chapter build; opening a project asks for the
connection to them.
